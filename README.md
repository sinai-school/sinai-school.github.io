# إعدادية سيناء للبنين

التطبيق والنظام الرسمي لـ **إعدادية سيناء للبنين** (ثانوية سيناء سابقاً) — المديرية العامة لتربية بغداد الرصافة الأولى.

- الموقع والتطبيق: https://sinai-school.github.io
- تطبيق الأندرويد والهواوي: https://github.com/sinai-school/sinai-school.github.io/releases/latest/download/sinai-school.apk
- الآيفون: افتح الموقع بـ Safari ثم «إضافة إلى الشاشة الرئيسية».

جدول الدروس، بوابة المدرسين والطلاب، والتبليغات. يتحدّث تلقائياً من نظام المدرسة.
